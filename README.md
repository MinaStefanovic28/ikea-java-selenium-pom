# IKEA E-Commerce Automation Framework

Automated UI test suite for the IKEA online store. 
The project is built with Java, Selenium WebDriver, and JUnit 5, implementing the Page Object Model (POM) design pattern.

## Technologies Used
* Java 17
* Selenium WebDriver
* JUnit 5
* Maven

## Project Structure
* `src/main/java/` - Contains Page Object classes for page element mapping and interactions
* `src/test/java/` - Test scripts validating UI functionality and assertions
* `pom.xml` - Maven configuration file for managing project dependencies

## Setup and Run Instructions

1. Clone the repository:
   git clone https://github.com/MinaStefanovic28/ikea-java-selenium-pom.git

2. Run tests via Maven:
   mvn clean test
